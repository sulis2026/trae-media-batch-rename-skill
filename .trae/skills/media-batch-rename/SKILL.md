# 媒体文件批量重命名（剪辑友好）

将杂乱命名的图片/视频（哈希名、相机编号、`copy_`、`raw_` 等）按统一格式批量重命名，
方便剪辑软件按顺序导入、按文件名快速识别画面内容。

## 一、适用场景

- 外置盘（移动硬盘 / U 盘）或本地任意文件夹中的图片 + 视频素材
- 用户意图关键词：批量重命名 / 改名 / 方便剪辑 / 整理照片 / 素材命名
- 文件夹名作为主题前缀（例：`半月湖`、`露营烧烤`）

## 二、命名格式（默认方案）

```
<主题>_<YYYYMMDD>_<NN>_<内容特征>.<原扩展名>
```

| 字段 | 说明 |
|---|---|
| 主题 | 文件夹名（用户可覆盖） |
| 日期 | 拍摄日期，取 `kMDItemContentCreationDate` 的本地日期；若无 EXIF，退化为文件修改日 |
| 序号 | 两位 `01–99`，按拍摄时间升序；超过 99 张自动升为三位 |
| 内容特征 | **必须**：2–4 个中文字，体现该素材最突出的主体 / 画面，文件间尽量有区分度 |
| 扩展名 | **保留原扩展名**，JPG/HEIC/PNG/MP4/MOV/MKV/WEBP 等原样保留 |

**示例：** `露营烧烤_20260831_09_黑狗围观.JPG`、`半月湖_20260830_04_芦苇晚霞.HEIC`

### 用户可选替代格式（第一步须询问）

| 选项 | 格式 | 适用 |
|---|---|---|
| A（推荐） | `主题_日期_NN_特征.ext` | 本次会话已采用 |
| B | `主题_日期_NNN_特征.ext`（三位序号） | 素材量 ≥ 80 或后续可能补充 |
| C | `主题_日期_NN.ext`（无特征） | 文件名要短、用户自己认得 |

**必须在重命名前让用户选定格式，不要默认跳过询问。**

## 三、完整执行流程

### Step 1 · 定位文件夹并列出媒体文件

1. 若用户未给绝对路径，用 `find /Volumes -type d -name "*<关键词>*"` 搜索（同时搜 `~/`）
2. `ls -la <路径>` 列出所有文件，过滤掉 `._*` macOS 资源分支文件
3. 向用户确认：找到 N 张图片 + M 个视频，位于 XX 路径，对吗？

### Step 2 · 取 EXIF 并按拍摄时间排序

对每个媒体文件执行：

```bash
mdls -name kMDItemContentCreationDate -name kMDItemPixelWidth \
     -name kMDItemPixelHeight -name kMDItemDurationSeconds "<文件>"
```

**排序键**：`kMDItemContentCreationDate` 升序（缺此值的用 `ls` 时间兜底，并在方案中标注「无 EXIF」）。

**分类输出**：
- 图片：记录尺寸，标注横图（W>H）/ 竖图（H>W）
- 视频：记录分辨率 + 时长（秒）

### Step 3 · 视觉识别内容特征（关键）

- **图片**：委托视觉子代理（`general_purpose_task`，或使用 Computer Use 打开 Preview / Quick Look）
  逐一查看，每张给 2–4 个中文字关键词。
- **视频**：用 QuickTime 或 Quick Look 打开后截首帧 / 中间帧，同样 2–4 字。
- **关键词原则**：突出主体、动作、景别、情绪、趣味点；避免重复；方便剪辑筛选
  （如「烤串特写」≠「烤串近景」，「黑狗围观」是独特点）。

### Step 4 · 展示方案 → 用户确认

以表格呈现完整映射（原文件名 → 新文件名），包含：序号、原文件名、新文件名、尺寸/时长备注。
**重命名前必须展示映射表并让用户确认。**
（若用户之前已选 A 格式且无异议，也可同时展示表并要求"确认执行"——但不能完全跳过此步。）

### Step 5 · 执行重命名

1. 首选：在目标目录下，所有文件一条 Shell 命令内用 `mv` 串联执行
2. 用 `requires_approval: true` 发起（外置盘大概率被沙盒拦截，审批模式可部分放行）
3. 一次命令执行后：
   - 若全成功 → 列目录核对，结束
   - 若部分成功 → `ls -1` 查当前状态 → 对剩余文件**再重试一次**带审批
   - 若重试仍被沙盒拦截**连续两次** → **停止无效重试**，切换 Step 5b

**Step 5b（沙盒兜底，必须提供）**：

把未完成的 `mv` 命令以完整可复制代码块形式交给用户，让其在系统 Terminal 粘贴执行，
每条命令一行，带 `cd` 到目标目录：

```bash
cd "/Volumes/KODAK/.../<文件夹>"
mv "原名1" "新名1"
mv "原名2" "新名2"
...
```

告知用户：粘贴后回车即可，完成后告诉我核对。

### Step 6 · 最终核对与交付

- `ls -1 <路径>` 列出当前所有文件
- 按序号排列，标注已完成 / 未完成
- 给用户一句总结：共 N 个文件，M 张图片 + K 个视频，命名规则 XX，全部 ✅ / 剩 X 个请用终端命令

## 四、注意事项

- **绝对不要删除 `._<name>` 资源分支文件**——它们是 macOS APFS 在外置盘上生成的元数据，
  忽略即可，不要 `rm`。
- **扩展名永远保留大写**（`.JPG` / `.HEIC` 原样），不要强制改成 `.jpg`。
- **序号永远按时间连续**：即使有扩展名不同的视频（MP4 / MOV）插入中间，序号也
  跟全局拍摄时间走，不单独给视频开新段。
- **不要在 SKILL 中包含任何用户真实路径或个人数据**——以上示例路径全部为占位符。
- 沙盒连续失败时，**不要硬试三次以上同样的命令**，直接切到终端粘贴兜底。

## 五、快速自检清单（执行前过一遍）

- [ ] 文件夹位置与数量已让用户确认
- [ ] 命名格式（A/B/C）已让用户选择
- [ ] 按拍摄时间排好序（视频与图片全局混排）
- [ ] 每个素材都有 2–4 字独立特征词，互不重复
- [ ] 展示了映射表，用户确认
- [ ] 执行顺序：先审批 mv → 再兜底终端命令
